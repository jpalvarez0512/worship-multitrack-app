# 📦 Centro de Entregables del Proyecto (deliverables/)

Esta carpeta contiene todos los productos formales, especificaciones arquitectónicas, manuales de usuario y compilaciones binarias de **Worship Multitrack App**.

---

## 📂 Organización de Entregables

```text
deliverables/
├── README.md               # Este catálogo índice
├── architecture/           # Especificaciones de diseño, modelos de datos y protocolos
│   └── system_architecture.md # Arquitectura integral y modelo de sincronización
├── builds/                 # Paquetes ejecutables y aplicaciones móviles
│   ├── android/            # Archivos .apk compilados para tablets y teléfonos
│   └── pc/                 # Ejecutables portátiles (.exe) o scripts de inicio
└── docs/                   # Manuales de usuario, guías de operación y reportes
    ├── sound_operator_guide.md # Manual para el operador de sonido en cabina
    └── musician_guide.md       # Guía para músicos en plataforma
```
